# Проектная работа: Архитектура безопасности PropDevelopment

## Описание
В данном репозитории содержится проектное решение по обеспечению информационной безопасности для компании PropDevelopment (Спринт 5).
Решение включает в себя анализ рисков, классификацию данных, проектирование безопасных интеграций и настройку RBAC/Network Policies в Kubernetes.
